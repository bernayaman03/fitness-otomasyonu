# Fitness Health App

Fitness Health App is a desktop fitness management application developed using C# Windows Forms and SQLite.

The application allows users to register, log in, select gym membership plans, and complete membership payments. Users can also explore workout exercises by selecting specific body areas through an interactive visual interface.

## Features

- User registration and login
- Gym membership plan selection
- Membership payment process
- Interactive body area selection
- Workout exercise recommendations for selected muscle groups

## Technologies Used

- C#
- Windows Forms
- SQLite
- Visual Studio

## About the Project

This project was developed as an educational desktop application, combining gym membership management with a simple workout guidance system.
